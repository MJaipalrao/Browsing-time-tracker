# 🕒 Browsing Time Tracker

A Chrome Extension that helps users track, analyze, and improve their browsing habits. It records active browsing time, categorizes websites, and displays detailed analytics through an interactive dashboard.

![Browsing Time Tracker](browser_extension.png)

## ✨ Features

- ⏱️ Track active browsing time
- 📊 Interactive dashboard with charts
- 🌐 Domain-wise browsing statistics
- 📂 Automatic website categorization
- 🕒 Timeline of browsing activity
- 📈 Productivity reports and insights
- 📅 Weekly and monthly summaries
- 📥 Export browsing data (CSV/JSON)
- ⚙️ Easy-to-use settings
- 🔒 100% Local Storage (Privacy First)

---

## 🖥️ Screens

- **Extension Popup** – Quick summary of browsing activity.
- **Dashboard** – Displays statistics, charts, and reports.
- **Categories** – Shows time spent in different website categories.
- **Timeline** – Displays browsing history in chronological order.
- **Top Links** – Most frequently visited websites.
- **Domains** – Time spent on each website.
- **Reports** – Productivity score and monthly summary.
- **Settings** – Manage tracking and export data.

## 🚀 Installation

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/Browsing-Time-Tracker.git
```

2. Open Chrome and go to:

```
chrome://extensions/
```

3. Enable **Developer Mode**.

4. Click **Load unpacked**.

5. Select the project folder.

6. Start using the extension.
